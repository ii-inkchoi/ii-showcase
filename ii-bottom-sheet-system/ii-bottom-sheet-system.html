Overview

II's bottom sheet pattern is a single component with two content layouts: action sheet (title plus body plus CTAs) and selection sheet (title plus value list). Hierarchy is built from luminance only — no weight variation, no color accents. The system follows II severe doctrine: declarative tone, friction at decision points, no consumer-modal flourish.

Friction is the primary distinction between use cases. Commitment moments (capital allocation, irreversible actions) block reflexive dismissal — only the X button works. Informational moments allow swipe-down and backdrop tap. The visual treatment is identical across both; the friction lever is invisible until the user tries to dismiss.

02

Categories

Three categories defined by consequence and dismissal model. Visual treatment is shared; only dismissal behavior differs.

Commitment

strict dismiss · X only

Capital allocation, irreversible actions, decisions that lose progress when dismissed. Buy gates, exit confirmations, cycle-skip commitments. Reflexive paths blocked: swipe-down and backdrop tap do nothing. The X button forces an intentional tap.

Informational

open dismiss · X, swipe, backdrop

Method picker, completion status, actions without major consequence. Upload option, success notice, simple confirmations. All dismissal paths allowed — the user can leave reflexively.

Selection

open dismiss · value picker

Form value picker. Items are values, not actions — equal weight, no primary or secondary. No arrow prefix. Hairline-separated rows. Tap on item commits the selection and dismisses the sheet.

CTA hierarchy and states

Two-tier hierarchy. Primary white, secondary gray. No tertiary in this pattern. Hierarchy comes from luminance only — no weight or size variation.

Tier definition

Primary is the in-context recovery path. Secondary is the alternative or external action. When a sheet has only one CTA, it is primary by default.

Primaryin-context fix · most common path
Secondaryalternative · requires external action
Selection itemsall equal · no nudge

State matrix

Disabled is rare in this pattern. If it appears often, the trigger logic should be reviewed. Loading uses opacity-only fade — no spinners or haptic celebration.

06

Copy rules

Sentence case throughout. Declarative tone. No questions, no urgency, no reassurance. State the fact and the action — let the reader decide.

Title

≤ 6 words · sentence case · declarative
  • Sentence case
  • Declarative statement of the situation
  • No question marks, no exclamation marks
  • State what is, not what the user feels
Are You Sure You Want to Exit? Exit bank connection

Body

≤ 2 sentences · sentence case · factual
  • Full sentences with periods
  • State of fact: what will or has happened
  • No reassurance ("don't worry"), no apology ("sorry to interrupt")
  • Numbers formatted consistently ($619.90 CAD)
Oops! It looks like you don't have enough funds. This order requires $619.90 CAD. You have $500.00 CAD available.

CTA

≤ 4 words · sentence case · verb + object
  • Verb plus object form
  • Action sheets prefix with arrow icon
  • Selection items have no prefix (they are values)
  • No urgency words ("now", "today")
  • No persuasion words ("easy", "quick")
Click Here to Adjust Now! → Adjust order

Forbidden across all surfaces

  • Emoji or icons inside copy
  • Title Case (all words capitalized)
  • ALL CAPS
  • Marketing adjectives — easy, simple, powerful, amazing
  • Beat the market, outperform, urgency CTAs
07

Dismiss behavior

Friction lever. Strict dismissal blocks reflexive paths. The X button always works — but for commitment moments it is the only way out. Tapping is intention; swiping is reflex. In a discipline-driven product, reflex is the enemy.

X buttonalways works · all variants
Commitment · strictX only · swipe blocked · backdrop blocked
Informational · openX · swipe-down · backdrop tap
Selection · openX · swipe-down · backdrop tap
Action button completioncloses sheet automatically

Motion

Heavily damped, deterministic, unremarkable. No bounce, no spring, no haptic celebration. The micro-delay introduces patience as a value — breaks reflexive scrolling.
