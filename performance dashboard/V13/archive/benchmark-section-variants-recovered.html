No CTA box: in this product nothing else asks to be pressed, blocks are doors (the V11 rule is block tap = navigate, with a quiet › in the gutter), so a boxed button is the one element on the page speaking another product's language. Instead the last line is a contents line, it names the actual dashboard sections waiting behind the tap, which is the honest version of "& more". And the chart carries the whole table: each line ends in its own name and value, so the legend, the y-axis, and the Portfolio / S&P Equivalent rows all collapse into two labels, and the bracket between the endpoints prints the difference at the only place it physically exists, the gap between the lines.
