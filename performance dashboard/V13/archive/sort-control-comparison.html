Sort control, five options

The word "Sort:" costs width in a filter bar that already overflows, and it is the only control on the page that names its own function instead of showing its state. Each option below is the real filter bar at 390px, with the real chips beside it, so the width it frees is visible too.

The two-headed glyph is the platform sign for "sorted by" (iOS arrow.up.arrow.down, Material sort). It is deliberately not a single arrow: ▲▼ already mean beat / trailed on this page, and › already means drill in. Each part does distinct work. Glyph = sorted by, word = by what, chevron = tap to change.

Option 3 failed only because the value sat in the same run as the chips and read as a sixth filter. A rule fixes exactly that, and it is already this file's device for "a different kind of thing starts here": the market strip sets the clock off from the flags with it, and the Monthly grid fences off Annual with it. So the separation gets made without inventing a glyph, and the value can stand alone the way every other control on the page does.
