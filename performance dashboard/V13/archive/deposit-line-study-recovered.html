Does the chart tell you whether you actually made money?

Pressure test of the main dashboard's benchmark chart against the question raised on 2026-08-28. Every frame below is the same 393px section, same design system, same data engine.

You started at 50,000 and the portfolio is worth 500,000, so it looks like it grew. But you put 600,000 in. You are actually down.

1. The gap, and the fix

Same account, same numbers, in both frames. The only difference is one extra line: cumulative net deposits. It is a step, not a curve, because money arrives on specific days and sits flat in between. Where the account line jumps at the same instant the step jumps, the jump was cash, not performance.

Today the section only ever answers the second one.

Colour was asked for so the two lines separate. One line is enough to do that, and one line is all the product's monochrome rule can absorb. The gold is the muted partner of the existing --c-review token (#FBC308), so no new hue enters the system, only a new role.
