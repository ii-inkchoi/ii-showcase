Tracking is three values plus one signature. Display and 34u headings −0.02, prose 0, mono +0.04, stat figures −0.069. They are three optical corrections, not decoration: large type looks loose so it tightens, reading sizes are optimal as designed, small all-caps mono closes up so it opens. Flattening everything to 0 narrows mono labels 6.3% and widens display 4%. Retired values −0.0343 / −0.00625 / −0.00556 are validator errors, and letter-spacing on html, body is forbidden.

Spacing is carried by margins only. A flex gap stacks on top of margin-top, which is the most repeated defect on these pages, a 24 intent rendering as 48, 64 or 80. Set row-gap:0 on vertical flex and grid containers and let the margins do the work. Hairlines are symmetric: the air above a rule matches the air below it.
