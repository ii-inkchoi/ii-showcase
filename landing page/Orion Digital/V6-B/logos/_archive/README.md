# V3/logos/_archive

## mogo-black.png (archived 2026-09-08)

A chroma-keyed raster made before a vector asset existed: the supplied Mogo file carried a
full-canvas white rectangle behind the wordmark, and keying it out of a flattened PNG left
the mark rendering as a black plate with white letters on 02's light cell.

Replaced by `mogo-black.svg`, which is the supplied vector with that backing rect removed and
its fills on currentColor, so the mark inherits the cell's text colour and has no plate at
all. 36KB to 1.7KB as a side effect.
