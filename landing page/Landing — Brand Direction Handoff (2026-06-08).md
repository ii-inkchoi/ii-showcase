# II Landing Page — Brand Direction Handoff

> **이 문서 용도:** Claude Code 세션(2026-06-08)에서 II 랜딩 페이지 방향을 잡은 대화 전체 기록. Cowork(또는 다른 협업자)가 이 한 파일만 읽고 *이어서* 비주얼/아이디에이션을 진행할 수 있도록 만든 self-contained 브리프. 빠짐없이 기록함.

---

## 0. 한 줄 요약

II 랜딩 페이지를 만드는 중. 방향이 잡혔음: **제품(앱) = Direction A(severe system), 랜딩/마케팅 = Direction B(editorial 발행물).** 공통분모 = **intelligence as status.** 현재 조직 metaphor 후보 = **"페이지 = 하나의 edition / 발행된 문서 (The Memo의 형식을 페이지가 입음)."** 아직 final 아님. 다음 단계 = 비주얼 톤(B 칼럼) 확정 → 실물 빌드.

## 1. 제품 컨텍스트 (II)

- **II (Intelligent Investing)** — 모바일(MVP 기준 mobile-only, 393px) self-directed 투자 앱. 대부분 retail 플랫폼이 *망상으로 돈 번다*는 믿음에 반대 — humility가 high-status.
- 핵심 메커니즘: 사용자가 자기 thesis를 **The Memo**(봉인된 투자 메모: thesis · kill criteria · valuation · calibration)로 묶고, 시장에 대해 책임지게 함.
- 두 트랙: **Self-Directed**(본인 운용 + II 규율) / **Managed**(Mogo 위임).
- 브랜드: severe, institutional, monochrome. **Bloomberg / Palantir 톤. 절대 Robinhood / Wealthsimple 아님.**

---

## 2. 전략 프레임 — 회장 디렉션 (canonical, 그대로 인용)

> 회장이 공유한 원문. 이게 모든 방향의 상위 기준.

- **Direction A — The System**: grids / geometry / documentation / intelligence / operating system / research. Feels like **Palantir · Anduril · Bloomberg · Stripe Press · MIT Media Lab.** Message: *"Serious people making serious decisions."* 위험: 지적으로 존경받지만 문화적으로 매력 없음.
- **Direction B — The Cult**: editorial / mystery / scarcity / fashion / cultural signaling / anti-corporate. Feels like **Anthropic · A24 · The Row · Acne Studios · independent magazines · luxury fashion editorials.** Message: *"Not everyone belongs here."* 위험: substance 없이 미감만.
- **Anthropic 관찰**: 둘 다 함 — 표면은 cultural sophistication, 제품은 serious research laboratory. "AI for thoughtful people."
- **회장 결론 (핵심):**
  - **제품 = Direction A** (allocator workstation / underwriting system / research platform / decision journal. severe·disciplined·institutional. Bloomberg/Palantir/Aladdin.)
  - **브랜드/캠페인 = Direction B에서 *선별* 차용** (independent publication / rare book / design journal / cultural artifact / architecture magazine. **NOT finance/investing/fintech marketing.** Anthropic 포스터 / A24 / The Row.)
- **가장 큰 인사이트:** 공통분모는 luxury가 아니라 **intelligence as status.** 돈/부/성공/수익이 아님. 전통 luxury = "I have more". 이 레퍼런스들 = **"I see something you don't."** II가 점유할 더 강한 영토.

## 3. 확정된 결정 (locked)

1. **운영 모델:** 제품 = A(system) / 랜딩 = B(editorial). 공통분모 intelligence as status.
2. **디자인 register:** 랜딩은 product design system을 따르되 **all-caps 없음**, ChakraPetch 없음(Inter only), **색은 극도로 최소(사실상 순수 모노/다크, accent 안 씀)**.
3. **타입:** 앱은 scale이 한정되지만 **랜딩은 flexible — editorial display로 크게/자유롭게.** product type scale에 갇히지 않음(design-guard off-scale warning은 의도된 예외).
4. **이미지 = primary 레이어** (레퍼런스가 전부 image-forward). 단 종류 규율: **B&W · grainy · 어둡 · 추상**(눈/손/텍스처/지오메트리). **라이프스타일·웃는 사람·폰 든 손 = 금지.**
5. **narrative 방향:** feature 나열(SaaS 카탈로그) **버림** → 명제(assertion) 기반. The Memo = 페이지가 도는 단일 오브젝트.
6. **Hero 제품 비주얼:** desktop 대시보드 아님(제품은 mobile-only). 실제 모바일 앱 스크린(severe)을 도판으로.

## 4. ★ 중요한 수정 — Palantir 오분류 (반복 금지)

대화 중 Claude가 "랜딩을 Palantir 느낌으로"라고 밀었는데 **이건 카테고리 오류였음.** 회장은 **Palantir를 Direction A(제품/시스템)** 에 명시적으로 넣었음. Palantir는 **editorial(B)이 아님.**

- **Palantir = 제품(앱)의 레퍼런스(A).** 이미 만든 severe 앱이 이걸 따름.
- **랜딩의 레퍼런스 = B 칼럼:** Anthropic 포스터 / A24 / The Row / Acne / independent magazines / luxury fashion editorial / architecture magazine / rare book / design journal.
- 랜딩 = **B 감성의 발행물**이 그 안에 **A 감성의 제품 도판**을 전시.
- 따라서 Palantir "Our Software" monumental 워드마크 리스트 같은 무브는 **랜딩엔 부적합**(그건 시스템 회사가 기능 파는 A 방식).
- **"edition/document" 아이디어 자체는 유효** — 그건 Palantir가 아니라 정확히 B(회장 단어: independent publication / rare book / design journal). 라벨만 잘못 붙였던 것.

**미해결 질문 (사용자가 후자로 기운 상태):** "Palantir 같은 느낌으로"는 → 제품 **도판(앱 스크린)에만** 적용(A라 맞음), 랜딩 톤은 **순수 B**로. Claude 의견도 후자.

## 5. 현재 조직 metaphor 후보 — "페이지 = edition"

> **랜딩 페이지 = 하나의 edition / 발행된 문서.** "메모에 관한 마케팅 페이지"가 아니라 **페이지 자체가 The Memo의 형식을 입은 발행물.** 제품이 "문서를 써라" 하니 랜딩도 문서다.

흔한 B2B 템플릿(hero→features→proof→CTA)을 탈출하는 장치:
- Edition 프레이밍 전체 관통 — masthead/colophon, `No. 01`, 날짜, 뒤표지식 마무리. CTA는 발행물처럼 절제.
- 섹션이 아니라 **"entries / plates"** — 번호 매긴 도판. 제품 스크린은 *전시물(Fig.)* 로 캡션.
- 기술적 marginalia를 장식으로 — 좌표 · 티커 · `//` · code-form 라벨(Intersect 포스터식).
- **worldview 우선, 제품은 증거.** 페이지의 일 = conversion이 아니라 *지위 부여*. "남들이 못 보는 걸 본다"를 *느끼게*.

### Claude 의견 (직설)
- edition 방향 **맞다, 제일 좋은 아이디어. 밀고 가야 함.**
- **단 진짜 우려:** edition/art-object는 *예쁜데 안 팔리는* 함정. 처음 온 사람이 II가 뭔지/왜 계좌를 여는지 모르면 "I see something you don't"이 "이게 뭔지 모르겠다"로 뒤집힘(회장이 경고한 full-B). → **clarity 먼저, mystery 나중.** 첫 한두 화면에 substance가 분명히 꽂히고 그 다음 신비.
- **베팅할 핵심 하나:** "페이지가 곧 The Memo, No. 01." 차별성은 *edition/document 규율*이지 dark-geometry 쿨함이 아님(과하면 흔한 "dark cool 스타트업"으로 추락).
- **프로세스 의견:** editorial은 텍스트 스펙으로 판단 불가. 스펙 더 돌리지 말고 **cover + 첫 entry 한 화면을 high-fidelity로 실물** 만들어 보는 게 백 배 빠름.

## 8. 제품 vocabulary & 사실 (Cowork 그라운딩용)

- **Underwrite 플로우:** Classify → Size → Investment Case → Calibration → **Capital Decision(buy).**
