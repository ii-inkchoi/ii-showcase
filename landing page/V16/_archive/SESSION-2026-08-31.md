## 5. ⚠ 측정 함정 — 반드시 지킬 것

이 세션에서 **존재하지 않는 값을 여러 번 보고했다** (레이블 간격 78·56, press-release 69,
get-the-app 56, 섹션 패딩 226/116 등). 원인은 전부 동일하다.

> `.rv` / `.ri` 리빌 애니메이션이 요소를 `translateY` 로 밀어둔 상태에서 측정

**측정 전 반드시:**

```js
d.head.insertAdjacentHTML('beforeend',
  '<style>*{transition:none!important;animation:none!important;transform:none!important;opacity:1!important}</style>');
d.querySelectorAll('.rv,.ri').forEach(e=>e.classList.add('in'));
```

**`shared/v11.css` 를 수정했으면 CSS 캐시도 무력화해야 한다** (HTML 만 cache-bust 하면 안 됨):

```js
const link=[...d.querySelectorAll('link[rel=stylesheet]')].find(l=>l.href.includes('v11.css'));
const fresh=d.createElement('link'); fresh.rel='stylesheet';
fresh.href=link.getAttribute('href')+'?cb='+Date.now();
await new Promise(r=>{fresh.onload=r; d.head.appendChild(fresh);});
link.remove();
```

기타:
- `<span>` 이 `display:block` 이면 Range 측정값은 글자 폭이 아니라 **블록 박스 폭**이다.
  타이틀 잉크 폭은 각 span 의 텍스트 노드에 Range 를 걸어야 한다.
- 프리뷰 패널이 `visibilityState:hidden` 이면 `requestAnimationFrame` 이 멈춘다. 캔버스 렌더는 검증 불가.
- Python 슬라이싱으로 HTML 블록을 잘라 옮길 때 **범위가 넘치는 사고가 세 번** 났다.
  큰 블록은 슬라이스 대신 **섹션 본문을 통째로 다시 쓰는 쪽**이 안전하다.
