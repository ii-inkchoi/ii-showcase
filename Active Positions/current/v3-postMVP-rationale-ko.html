회장 v2 대비 변경 사항 — Rationale

# 변경 Rationale
1 페이지 타이틀 위에 계좌 scope 라벨 추가 (예: “RRSP”, “All accounts”) 단순 “74%” 같은 % 는 self-describing statement가 아님. Scope에 따라 의미가 다름 (같은 종목이라도 RRSP weight와 all-accounts weight가 다름). 명시적 scope 라벨 없으면 사용자가 이 % 가 무엇 기준인지 추측해야 함. 라벨로 scope을 명시하면 그 ambiguity가 사라짐. Doctrine §10 (statements over explanations) 요구사항 — “5%” 단독은 statement 아님, “RRSP의 5%” 가 statement.
2 Held 컬럼 → Held / Horizon (예: 1.5y / 3y) 단순 “들고 있는 시간” 은 자동 계산 데이터일 뿐 — 시스템이 이미 아는 것을 사용자에게 보여줄 뿐. II에서 중요한 건 사용자가 진입 시점에 한 commitment를 지키고 있는지. held / horizon 표시는 컬럼을 “경과 시간” 에서 “본인 commitment 대비 진행률” 로 reframe함 — Doctrine §11 friction 원칙과 §13 memo 원칙을 list 레벨에 시각화. held == horizon 일 때 자체가 re-calibration 시그널.
3 Daily price + Daily ±% 제거 Doctrine §15가 명시: intraday noise를 minimize, activity는 returns과 negative correlation. Primary list에 daily ±% 를 보여주면 사용자가 매일 들어와 반응하도록 학습됨. Value 컬럼이 이미 today price 반영함 (market value = shares × current price) — today 영향은 암묵적으로 보임. 명시적 % 는 어제 vs 오늘 비교를 유도, 이게 Doctrine §3 Enemy (Noise + Short-termism + Impulse) 활성화. Daily 가격 검사처는 Stock Detail / Market 탭 — 사용자가 의도적으로 들어간 surface.
4 CAD 통화 표기를 row → column header (“Value CAD”) List의 모든 값이 자동으로 CAD 환산됨 (USD 종목 포함). 매 row마다 “CAD” 반복은 시각 무게 추가, 정보 추가 X — 사용자가 컬럼 의미 이해하면 충분. 단일 표기 (header에 한 번) 충분. Doctrine §1: do not explain more than is necessary.
5 Calibration 데이터 list에 의도적으로 미포함 — confidence와 calibration plot은 Stock Detail에만 Calibration은 시스템의 본질이지만, Active Position list는 orientation surface (Doctrine §14 논리를 list에 적용). 80%·76% 같은 paired numeric은 헤더 레벨 explanation이 필요한데 (“어느 게 내 거?”), 그 explanation 자체가 시각 무게 추가 — Doctrine §1과 충돌. Stock Detail의 calibration plot (선 + 위/아래 점) 은 시각적으로 self-explanatory, 이 challenge의 올바른 home. List에서 빼면 사용자가 self-evaluation metric을 매일 슬쩍 보는 습관 안 들이게 됨 (Doctrine §15).
6 정렬 룰: 페이지 타이틀 우측 / 숫자 컬럼 우측 / 글자 라벨 좌측 Doctrine §8은 “no centering, ever” 라고만 함, 모든 것을 좌측 정렬해야 한다고는 안 함. MVP 시스템은 이미 일관된 컨벤션에 수렴: 페이지 타이틀 우측 정렬 (식별 anchor), 숫자 컬럼 우측 정렬 (functional magnitude scanning), prose와 글자 라벨은 좌측 정렬. v3는 한 화면만 예외를 두지 않고 시스템 컨벤션을 따름. Doctrine §8에 Alignment Rules subsection 추가됨.

v3가 v2에서 의도적으로 유지하는 것

우측 정렬 페이지 타이틀, dense tabular layout, 브랜드 컬러 부재, sans-serif 타이포그래피, asymmetric 구성 — 이 모두 변경 없이 그대로 유지. v3는 회장 v2로부터의 시각적 이탈이 아니라, 의도의 정밀화.

Doctrine references

  • §1 — Do not explain more than is necessary. Mystery is preserved by withholding.
  • §6 — ICP: willing to be measured, challenged, and proven wrong in order to improve.
  • §8 — Visual Design (Severe Mode) + Alignment Rules.
  • §10 — Tone of voice. Statements over explanations.
  • §11 — Friction Doctrine. Friction belongs at capital allocation, not at reading flows.
  • §13 — Memos as Living Documents. Records of thought over time.
  • §14 — Dashboard restraint. Orientation surface, not decision surface.
  • §15 — Behavioral Constraints. Silence is a feature.

Dependencies

Calibration 페이지 (현재 WIP) 가 buy 시점에 probability와 horizon을 capture해야 함 — Held / Horizon이 list에서 작동하려면 필요. 4 surface (Dashboard, Active Position, Stock Detail, Holdings) 일관된 account scope 모델 필요. 모든 종목을 일관된 CAD 값으로 표시하기 위해 USD-to-CAD 환산 로직 (data layer).

이 list가 아닌 것

이건 daily 가격 변동 추적하는 곳이 아님. Calibration 분석 도구가 아님. 계좌 전환하는 navigation hub가 아님. 내가 무엇을 가지고 있고, 그 결정들이 얼마나 의미 있는가? — 이 단일 질문에 답하는 orientation surface.
