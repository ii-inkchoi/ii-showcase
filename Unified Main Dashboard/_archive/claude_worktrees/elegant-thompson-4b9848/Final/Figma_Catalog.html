Unified Main Dashboard — Figma Export Catalog

A single catalog of every prototype state across the Unified Main Dashboard (Post-MVP). Organized by category with descriptions of what each section and scenario represents. Intended for import into Figma via the html.to.design plugin.

Project: Unified Main Dashboard · Post-MVP Surface: Mobile (390 × 780) Total Value (fully-active): 173,249.00 CAD
How to import into Figma
  1. Open this file locally in a browser (double-click Figma_Catalog.html inside the Final/ folder). iframes load via relative paths, so no password is needed.
  2. In Figma, run the html.to.design plugin and point it to this local file (or to each deployed scenario URL individually if iframe import is not supported).
  3. Each scenario card includes a title, short description, scenario ID, and a live render of the mobile screen.
