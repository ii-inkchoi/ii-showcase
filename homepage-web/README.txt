II Homepage — desktop + mobile review build
2026-07-27

HOW TO OPEN
  Open index.html in a browser.
  Desktop: any width. Mobile: resize the window below 900px, or use
  the browser's device toolbar (iPhone 14 / 390 x 844 is what this was built against).

WHAT IS IN HERE
  index.html            the homepage
  grid-overlay.js       press "g" on the page for a 12-column overlay
  Images/               the five stills the page uses
  Images/.../video from dave/   the four hero clips, recompressed for sharing
                                (1600px wide, ~20MB total instead of 350MB —
                                 quality is lower than the production files)
