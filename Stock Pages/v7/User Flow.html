Notes

  • 3 states determined by 2 booleans: atz-memo-version set? × atz-position-status === 'held'?
  • Intent routing: tapping the memo card sets intent=memo, tapping Capital Decision sets intent=buy. First-time flow uses this to decide whether to land on memo or continue to trade.
  • Row-edit pattern: from Memo Review (and CD Review), tapping any row goes to its Edit page. Save → back to Review. Consensus from the May 28 meeting: don't force users sequentially.
  • Save guardrail: bottom sheet appears only when edits exist vs the latest version. No edits = direct Continue (no popup).
  • Version permanence: writing V[N+1] never overwrites V[N]. All past versions live in atz-memo-history and are read-only via Historical page.
  • Quarterly alert: X dismiss = this view only. Memo save = permanently acknowledged via atz-alert-Q4-acknowledged flag.
  • Trade page is Leo's responsibility — placeholder in our build.
