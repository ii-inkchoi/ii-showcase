Stock Page · User Flow

Three entry routes converge on the Stock Page. Stock Page branches by persona. Memo creation and edit loop back to the Stock Page.

Entry
01 · Entry Main Dashboard Unified home view — positions, performance, open questions, search.
02a · List Active Positions (Full Page) All currently held names with thesis-health status.
02c · List Under Review (Full Page) Watchlist names — pre-position evaluation.
Stock Page
03 · Page Stock Page Branches by persona below — first-time (no memo) vs returning (memo Live).
First-time user Stock Page (First-time) No position, no memo. About company + Draft Memo CTA. Returning user Stock Page (Memo Live) Position held. Memo box with Thesis + Kill conditions + IV/MoS/Probability.
Creation flow · spec by Leo 9-Step Memo Creation Classify → Size → Thesis → Kill → IV → Compounding → Source → Note → Review (Hold to seal). Detail · Edit The Memo (Full Detail) 8 numbered sections matching the 9-step flow. Read or edit. Hold to seal creates new version.
↺ Hold to seal → back to Stock Page (now Returning, memo Live)
↺ New version (V3 → V4) → back to Stock Page (updated)
