The Memo · State Variants · V3

Three states in V3. Each state is fully determined by two localStorage values: atz-memo-live and atz-memo-draft. V2's five-state machinery (Triggered / Stale / Closed) is deferred until alerts and position state are wired into the memo layer.

01 · Live Live

Memo is sealed and current. Textarea content matches the sealed (live) version. Stock Page reflects this content.

Editing the sealed memo. Pending changes that haven't been re-sealed. Stock Page still shows the old live version.

03 · Sealed Empty Sealed Empty

User cleared and sealed an empty memo. No content, no badge dot. A deliberate reset state distinct from never-sealed.

Removed in V3: Triggered (kill criteria armed and breached), Stale (memo not re-underwritten in N days), Closed (position exited). These were V2 lifecycle ambitions on a structured memo. V3 single-textarea memo doesn't carry that machinery yet.

Future: Triggered may return when alerts surface on Stock Page reference the memo. Stale could return as a "Reviewed Xd ago" threshold-driven UI hint. Closed becomes a position-state concern, not a memo-state concern.
