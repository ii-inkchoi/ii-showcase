Stock Page · User Flow · v2

Three entry routes converge on the Stock Page. Stock Page branches by persona. Both personas can drill into pre-memo research tools (Fiscal AI for data, AI Research for protocol). Memo creation includes a planned Pressure Test fail-safe before seal. Memo loop-back returns to the Stock Page.

Full step-by-step in Structure/mogo-ii-ia.md §6.13.14.7. Doctrine references: Doctrine/Product Design Principles.md · Doctrine/Stock Page + Memo - Doctrine Update (May 2026).md §14–§16.

03 · Page Stock Page Branches by persona below — first-time (no memo) vs returning (memo Live).
First-time user Stock Page (First-time) No position, no memo. About company + Draft Memo CTA + drill-ins to research tools. Returning user Stock Page (Memo Live) Position held. Memo box with Thesis + Kill Criteria + IV/MoS/Probability + drill-ins to research tools.
Pre-Memo Research
Data surface · drill-in Fiscal AI · ATZ Dedicated workspace. Live Fundamentals, Valuation, Filings, Transcripts, Peer Comps. Bloomberg-style density. Protocol · drill-in AI Research & Analysis · ATZ 11-step protocol. 4 phases (Discovery / Stress / Value & Size / Synthesis). Copy each prompt → paste into Claude or ChatGPT.
Direct path from persona to memo creation also valid for users who skip pre-memo research tools.
Creation flow · spec by Leo 9-Step Memo Creation Classify → Size → Thesis → Kill Criteria → IV → Compounding → Source → Note → Review (incl. Pressure Test drawer · planned) → Hold to seal. Detail · Edit The Memo (Full Detail) 8 numbered sections matching the 9-step flow. Read or edit. Re-underwrite triggers a new version. Hold to seal returns to Stock Page.
↺ Hold to seal → back to Stock Page (now Returning, memo Live)
↺ New version (V3 → V4) → back to Stock Page (updated)
At Memo Review (planned) — Pressure Test drawer with 4 prompt options (Bear / Valuation / Kill Criteria / Compounding stress). Copy prompt + memo → paste into Claude → return to seal or revise. Optional fail-safe, not a gate.
